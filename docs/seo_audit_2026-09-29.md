## 3. Persian URL verdict

Keep Persian slugs. Google reads and displays them decoded, they match how the audience
searches, and the site already does the important things right: no Arabic ي/ك in slugs,
half-spaces folded, NFC, Latin digits, a single canonical per item, wrong slug / bare id /
trailing slash all 301 to the canonical, lowercase percent-encoding accepted. Median
encoded path is 165 chars (max 544) — long, but not an indexing problem. Fix the details
in #10 before submitting the sitemap, because right now the URLs are unindexed and
changing them costs nothing.

## 4. Not measurable from here

- PageSpeed Insights API rate-limited anonymous calls (429); CrUX has no field data for a
  site this size. Performance evidence above is network timing from an Iranian VPS.
- Full-sitemap URL inspection: the Search Console credential lives on the owner's
  laptop, so each inspection travels through the chat; after the sitemap is submitted,
  the Page indexing report gives per-URL status for free.
